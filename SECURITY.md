# Security & Threat Model - Cultural & Venue Smart Copilot Platform

The Cultural & Venue Smart Copilot Platform operates in high-density public environments where data safety, real-time availability, and AI output grounding are mission-critical. This document outlines our comprehensive security posture, threat model, and vulnerability reporting procedures.

## Enterprise Security Features

### 1. Authentication & Authorization (RBAC)
- **JWT Rotation & Blacklisting**: Access tokens (`15 min` lifespan) and refresh tokens (`7 days`) are signed securely using HMAC-SHA256 (`HS256`). Upon logout or token rotation, the token `jti` is immediately blacklisted in Redis (`token_blacklist:{jti}`).
- **Granular RBAC Hierarchy**:
  - `ADMIN`: Full access to venue creation, parking structure modification, and emergency broadcast triggering.
  - `VOLUNTEER`: Access to venue crowd monitoring and parking spot verification.
  - `USER`: Standard access to AI copilot chat, wayfinding calculations, and parking reservations.
  - `GUEST`: Read-only access to venue FAQs and general map layouts.

### 2. AI & Prompt Security Guardrails
- **Prompt Injection Defense (`PromptGuard`)**: Inspects every user message against regex patterns catching instruction overrides, system prompt reveal attempts, and developer jailbreak framing (`IGNORE ALL PREVIOUS INSTRUCTIONS`).
- **Data Privacy & PII Redaction (`PIIDetector`)**: Automatically masks sensitive patterns (`emails`, `phone numbers`, `Social Security Numbers`) into safe tokens (`[REDACTED_EMAIL]`) before transmitting prompts to external LLM providers (`Gemini` / `OpenAI`).
- **Grounding & Hallucination Defense (`HallucinationGuard`)**: Computes exact factual overlap between LLM completions and retrieved RAG vector document chunks. Responses scoring below our verification threshold (`0.70`) trigger an automatic grounding disclaimer.

### 3. Infrastructure & Network Hardening
- **HTTP Security Headers**: Every response generated by the application includes strict headers (`Content-Security-Policy`, `Strict-Transport-Security`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`).
- **Denial of Service (DoS) Protection**:
  - `RequestSizeLimitMiddleware` intercepts payloads exceeding `10 MB` before parsing.
  - Distributed `SlowAPI` rate limiter restricts registration (`10/min`) and login attempts (`20/min`), enforcing account lockout (`15 min`) after 5 consecutive failed login attempts.
- **Secret Entropy Validation**: `AppConfig` enforces OWASP password and secret key entropy checks at startup (`min 32 characters`, `uppercase + numbers + symbols required`).

## Reporting Security Vulnerabilities

If you discover a potential vulnerability within the platform, please do **NOT** open a public issue. Instead, report it privately to our security engineering team at `security@culturalcopilot.io`. We aim to acknowledge reports within 24 hours and issue remediation patches within 5 business days.
